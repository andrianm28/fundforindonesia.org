## Jebakan yang harus Anda tahu sebelum menyentuh branch

Lima kali sesi ini, carry branch **menghapus fix yang sudah merged** dan
GitHub melaporkannya `CLEAN`. Dua kali hampir salah, satu kali benar-benar salah
(`pr94-carried` akan me-rollback `ProviderBalanceInsufficientError` 3 → 0).

**Cek wajib sebelum merge apa pun** — `git diff --name-only origin/main <branch>`,
lalu per-byte untuk file yang harus utuh:

```bash
diff <(git show origin/main:src/lib/money/escrow.ts) <(git show origin/<branch>:src/lib/money/escrow.ts)
```

Kalau muncul `AGENTS.md`, `CONTEXT.md`, `prisma/schema.prisma`, `docs/adr/`,
`src/lib/money/reconcile/`, `src/app/api/admin/reconcile/` — **berhenti**, itu
isi usang. Abaikan `reconcile/route.test.ts`: deduplikasi `groupBy` ke
`tests/support/ledger-group-by.ts` itu disengaja.

**Jebakan kedua:** `git cherry-pick <sha>` dari branch lama bisa membawa 23
file tak terduga. Selalu `git diff --name-only origin/main HEAD` sesudahnya.

## Yang menunggu Dri

**Track A deploy** — urutannya penting, dan tidak ada bagian yang bisa dikerjakan
agen:

1. `deploy` user + `authorized_keys` dengan forced command — **lebih dulu**, kalau
   dibalik `DEPLOY_SSH_KEY` tidak punya tempat masuk
2. tentukan `DEPLOY_DIR`
3. salin `ops/deploy.sh` **dari `main`** — yang di host cuma 36 baris vs 318
4. seed `.env` — **reuse `DB_PASSWORD` kibi-clone**, kalau tidak volume 80 MB
   itu tidak terbaca dan data produksi tampak hilang
5. `DEPLOY_HOST`, lalu 3 secret + `NEXT_PUBLIC_BASE_URL` + `NEXTAUTH_URL`

`NEXTAUTH_URL` **di-bake ke image** dengan default `galang.fundforindonesia.org`,
sedangkan nginx melayani apex — kalau tidak di-set, callback auth salah.

Deploy sudah pernah dicoba (`gh workflow run deploy.yml --ref main`,
run `36377642236`): **`gate` lulus, `deploy` gagal** di `DEPLOY_HOST` kosong.
Tidak perlu mencoba lagi — 0 secrets, 0 variables, `deploy` user tidak ada.
Port 8093/18093 juga masih dipegang stack `kibi-clone`, jadi `up` akan gagal
**setelah** menarik image.

Satu perubahan yang hanya Dri bisa buat: **required reviewer** untuk environment
`production`. `protection_rules: []`, dan komentar `deploy.yml:17-19` mengklaim
deploy hanya jalan setelah owner menyetujui — yang saat ini **tidak benar**.
