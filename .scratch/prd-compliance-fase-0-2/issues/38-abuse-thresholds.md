# 38: Abuse thresholds and audit markers

**What to build:** Scrutiny scales with the amount at stake, without blocking anyone mid-donation.

**Blocked by:** 12, 18

**Status:** ready-for-agent

- [ ] Cumulative Gross above Rp100 juta on a Campaign triggers additional Verifier review
- [ ] Above Rp500 juta places an audit marker on the Campaign
- [ ] A single Donation above Rp50 juta is flagged for an Admin without being blocked
- [ ] At most three Active Campaigns before a Fundraiser's first Usage Report is accepted
- [ ] Thresholds are configurable, not hardcoded
