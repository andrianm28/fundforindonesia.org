# Vendored skills

The 25 skills here are copied from `mattpocock-skills` 1.2.3 (MIT, https://github.com/mattpocock/skills; licence in `LICENSE-mattpocock-skills`). They are committed so that Claude Code cloud sessions, which load only repo-committed skills, run the same workflow as local ones.

Do not edit them in place. To update: copy the new release's `skills/` over these directories (only the ones listed in its `.claude-plugin/plugin.json`), bump the version above, and open a PR.
