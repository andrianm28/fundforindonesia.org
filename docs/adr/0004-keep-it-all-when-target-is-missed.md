# A campaign keeps what it raised when the target is missed

When a Campaign's deadline passes below target it becomes EXPIRED, stops taking donations, and the Fundraiser can still request Payouts for the balance. We chose this over all-or-nothing (refund everyone) because the campaigns this platform serves are medical, disaster, and community needs where a partial sum still helps, donors on Indonesian platforms expect it, and all-or-nothing would require mass refunds that the money layer is deliberately not built to do. Reaching the target does not close a Campaign either; only the Fundraiser or an Admin marks it COMPLETED.
